# ADR 0009：PR 与主分支 CI

日期：2026-10-28。状态：Accepted。

PR 到 main 的 opened/synchronize/reopened 事件执行完整门禁；功能分支普通 push 不单独执行，避免与 PR 重复。push main 验证最终集成状态，另支持手动运行。新 PR 提交会取消同 PR 的旧运行，主分支不取消。只读权限、checkout 不持久化凭证、10 分钟超时；不使用 pull_request_target 执行贡献者代码，不注入 SEC 或云凭证。

Quality gate 使用 npm ci 与 npm run check，覆盖格式、类型感知 lint、架构/循环、类型和离线单元/CLI/缓存测试；不下载真实 SEC 文件。当前项目小，单 job 避免重复安装。未来确有耗时需求再拆 jobs。

远程为私有空仓库，需首次初始化 main 才有 PR 基线。GitHub branch protection API 实测返回 403：当前套餐需升级 GitHub Pro 或改公开才能启用；本次不改变可见性或购买套餐。工作流通过不等于强制禁止绕过合并，待套餐支持后将 Quality gate 设为 required、要求 PR 和分支最新、禁止强推/删除。
