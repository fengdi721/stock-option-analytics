# ADR 0003：报价快照、来源与 CLI

日期：2026-10-28。状态：Accepted。

## 决定

提供两个命令：payoff 接受明确的持仓权利金；quote-payoff 接受一个 CSV 快照和持仓请求，按 long 用 ask、short 用 bid 生成权利金。该假设不能保证真实成交。

每次请求必须明确 asOf 和最大报价年龄。相对于 asOf 拒绝未来或陈旧数据；可重复的历史场景不依赖执行时系统时钟。一个快照每个合约只有一条记录；拒绝重复、bid > ask 和缺失合约。输出包含每腿来源/时间戳、价格侧及 CSV SHA-256。source 标签是输入声明，不能证明数据真实性或授权。

当前采用明确受限的无引号 CSV 格式，严格列名和顺序，不猜测分隔符或静默丢弃坏行。单文件最多 2 MB，快照最多 10000 行。需要通用 CSV 引号/换行支持时引入经过验证的解析器并增加测试。

## 替代与后果

默认中间价会隐含更乐观的成交假设，因此本版用 bid/ask；未来可用显式参数选择，但必须保留 provenance。拒绝快照内任意坏行可能比仅校验选中合约严格，换来明确一致的数据质量边界。

先 CLI 而非 HTTP：输入输出契约与核心可重复测试后，再提供 UI/API。错误输出到 stderr、非零退出，正常结果只写 stdout。
